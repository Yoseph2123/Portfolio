# Portable Videos Directory

Place your edited video files in this folder (for example: `videos/my_edit.mp4`, `videos/commercial.mp4`).

### Why use this folder?
1. **100% Portable**: When you copy this `Portfolio` folder to a USB drive, another computer, or a ZIP file, your videos travel with the portfolio.
2. **Offline Ready**: Videos in this folder can be played directly by the browser without needing internet access or third-party hosting.
3. **Relative Paths**: In the portfolio, simply use the path `videos/your_video_name.mp4`.
